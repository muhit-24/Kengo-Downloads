# Kengo

### A Simple, Lightweight & Portable Video Downloader for Windows

Kengo is a minimal video downloader for Windows, designed to make downloading videos simple and straightforward.

No complicated setup, no unnecessary features, and no installation required. Just download, extract, and start using Kengo.

---

## ✨ Features

- **Simple Interface** – Clean and minimal user interface.
- **Portable Application** – No installation required.
- **Video Information** – Inspect supported video URLs before downloading.
- **Format Selection** – Choose from available video and audio formats.
- **High-Quality Downloads** – Download available video and audio streams.
- **Lightweight Experience** – Designed for a simple and responsive experience.

*Features may vary depending on the supported website and available formats.*

## 📥 Download

Get the latest version of Kengo from the GitHub Releases page:

1. Download the latest `Kengo` file.
2. Extract the ZIP file to your preferred folder.
3. Open the extracted folder.
4. Run `Kengo.exe`.

That's it! Kengo is ready to use.

## 🖥️ System Requirements

- Operating System: Windows 10 / Windows 11 (64-bit)
- Architecture: x64
- Internet connection for downloading videos
- Required supporting tools included with the release, where applicable.

## 🚀 How to Use

1. Launch `Kengo.exe`.
2. Paste a supported video URL into the input field.
3. Let Kengo inspect the available video information.
4. Select your preferred format and quality.
5. Start the download.
6. Find your downloaded video in the selected download location.

## ⚠️ Important Notes

- Kengo is a third-party desktop application.
- Download availability depends on the source website.
- Some websites may restrict access or change their download systems.
- Only download content that you own or have permission to download.
- Respect copyright laws and the terms of service of the websites you use.

## 🔒 Privacy

Kengo is designed to perform video processing and downloading locally on your Windows computer.

It does not require a Kengo account.
